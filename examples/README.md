# Example models

Every model here was generated by the AI assistant from a plain-English brief and built live in FreeCAD.
Open them with [FreeCAD](https://www.freecad.org/) 1.1 or newer.

| File | Brief (short) | Status |
|---|---|---|
| `SpurGearPair_3to1.FCStd` | 3 kW at 1450 rpm, 3:1 reduction, conveyor, case-hardened steel | FEA-verified in ANSYS. The gears are parametric FCGear objects, so install the **FCGear** add-on to edit them. |
| `Chevron_Lite_2m2.FCStd` | Innovative 2.2 m lake boat, LSAM-printed upright in PETG, 2 people + outboard | Buoyancy, stability and motor-mount FEA checked |
| `Chevron_Dinghy_2m2.FCStd` | Earlier, heavier version of the same brief | Superseded by Chevron Lite |
| `FlipCat_concept.FCStd` | Flip-over catamaran: 4-person pontoon face / 2-person fast face | Concept, checked in FreeCAD |
| `SwapTub_concept.FCStd` | Flip monohull for LFAM: ring hull + two swappable tubs | Concept, checked in FreeCAD |
| `MonoCat_single_print.FCStd` | Reversible catamaran as one large-format print | Concept, checked in FreeCAD |
| `Strider_2m4_PETG.FCStd` / `.stl` | 2.4 m trimaran joined by a 45° diagrid | Form concept only: the connecting webs can't be printed in one piece |

The full reports for the gear and the Chevron boat are in [`../reports/`](../reports/).
